# Feature checklist

Current project scope:

- [x] Add tasks with the button or Enter.
- [x] Mark tasks complete or active with the check control or task text.
- [x] Delete individual tasks.
- [x] Filter the list by all, active, or completed.
- [x] Track completion with a task count and progress indicator.
- [x] Persist tasks in this browser using `localStorage`.
- [x] Show an empty-state message when the current view has no tasks.
- [x] Provide responsive layout rules for narrow screens.
- [x] Include labeled controls, keyboard focus styling, and reduced-motion support.

Tasks remain local to the browser profile. The app does not provide accounts, server storage, or cross-device synchronization. Accessibility support is an ongoing goal and should be validated as the interface evolves.
