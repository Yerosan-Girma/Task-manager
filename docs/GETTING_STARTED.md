# Getting started

## Prerequisites

Install a current Node.js LTS release; npm is included with Node.js.

## Install and run

```bash
npm install
npm run dev
```

Open the local address printed in the terminal. Vite refreshes the page as you edit source files.

## Verify a production build

```bash
npm run lint
npm run build
npm run preview
```

The build output is generated in `dist/` and should not be committed.
