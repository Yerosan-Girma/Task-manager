# Contributing

Thanks for your interest in improving this project.

## Before making a change

1. Check the existing issues and pull requests for related work.
2. Keep changes focused and preserve the current add, complete, delete, filter, progress, and local-storage behavior unless the change explicitly proposes otherwise.
3. Avoid committing generated output such as `dist/` or installed dependencies.

## Local workflow

```bash
npm install
npm run dev
npm run lint
npm run build
```

Please run the lint and production build checks before opening a pull request. Include a short summary of what changed and how you checked it. For user-facing changes, describe the expected behavior and any relevant accessibility considerations.
